Research

  • HEVD — Write What Where (WWW) → Local Privilege Escalation Kernel
    HackSys Extreme Vulnerable Driver: arbitrary kernel write primitive. Overwriting HalDispatchTable+4 to redirect NtQueryIntervalProfile into shellcode. Full ring-0 → ring-3 token-stealing LPE chain on Windows 10. Covers null page mapping, SMEP state, shellcode stability.
  • Trick OR Deal — Use After Free: tcache Poisoning to RCE Heap
    "Trick Or Deal" PWN challenge. Controlled free() a straight forward Heap exploitation challenge featuring a UAF (Use-After-Free) vulnerability in menu provided in the binary.
  • Coming next : Capcom.sys — CVE-2016-7255: Signed Driver Abuse CVEKernel
    Vulnerable signed driver exploitation. IOCTL interface abuse to execute attacker-supplied shellcode with SMEP disabled via CR4 manipulation. Full user-mode to kernel code execution, shellcode relay, clean CPU state restore.

Tools — github.com/00xAuto

  • Nemesis AV-Bypass ShellC · AV Evasion · Winsock
    Windows reverse shell with XOR-obfuscated C2 config. IP never stored in plaintext — encrypted at build time, decrypted into a stack buffer then zeroed before connect(). No console window, stripped symbols, small binary footprint.
  • UUIDFuscation LoaderC · Shellcode Loader · Static AV Evasion
    Shellcode encoded as UUID strings, decoded at runtime with UuidFromStringA, executed from a heap-allocated RX region. Evades static AV signatures scanning for raw shellcode bytes in PE sections.
  • Special ODT Macro RCEPython · RCE · LibreOffice
    Generates malicious .odt files that fire a payload on open in LibreOffice. Dual-mode: reverse shell via dom:load macro event, or NTLM hash capture via embedded UNC path reference.
  • Minion HTB Auto-PwnPython · ICMP Shell · Scapy
    Full automated exploit chain for HTB: Minion (Insane/Windows). All TCP/UDP blocked — data exfiltrated over ICMP only using PowerShell Ping.Send() and Scapy sniffing. Interactive admin shell in pure ICMP.
  • IMAP Mailbox DumperPython · Post-Exploitation · IMAP
    Dumps every IMAP folder — headers and full body — to stdout post-credential-spray. SSL support, per-folder error handling, binary-attachment safe.
  • Windows SID ParserPython · AD Enumeration · LDAP
